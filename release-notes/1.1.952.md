# Sonetro 1.1.952

This release refines library playback, list alignment, and Home panorama motion.

## What’s new

- **Shuffle all:** replaced the music list’s source selector with a circled play action and song-title-sized text. Tap to choose a random playable song, enable library shuffle, and open Live.
- **Shuffle preparation:** moved queue preparation off the UI thread, reduced redundant work, and guarded repeated taps. A newer playback command takes priority over unfinished shuffle preparation.
- **Album artwork playback:** tapping an album thumbnail starts the album and opens Live, including albums listed inside an artist page. Album text still opens its details.
- **Artist alignment:** aligned artist names with their circled playback controls using font metrics.
- **Cloud-icon alignment:** aligned source icons with the visible song-title height across the shared title component.
- **Cleaner song lists:** now-playing indicators appear only in Queue. Queue rows reserve a consistent gutter so the indicator aligns with the header inset.
- **Artist page headings:** removed the third repeated heading while retaining looping swipes between albums and songs.
- **Home panorama rendering:** moved shared History/New motion into drawing layers to reduce repeated layout work.
- **Background motion:** made the New → Live background trail slightly longer while preserving wraparound endpoints and reverse-swipe continuity.
- **Internal cleanup:** renamed app-owned motion identifiers and removed unnecessary comments without changing animation values in that cleanup.

## Android compatibility

**Android 7.0 (API 24) or newer is required.** This version raises the minimum from Android 6.0. Devices running Android 6.0 cannot install this update; version 1.1.948 remains available in the release archive.

## Validation

Source compilation and targeted animation, panorama, and music-ordering tests passed during development. The supplied APK’s version and signing certificate were verified. These checks do not replace on-device visual and performance verification.
