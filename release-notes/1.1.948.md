# Sonetro 1.1.948

This update improves search input, server-address suggestions, contextual removal, and Back navigation.

## What’s new

- Fixed delayed local or server search results overwriting newer typing or restoring deleted text.
- Preserved Android text selection, cursor position, and composing text while editing search queries.
- Added previously connected server suggestions when the server-address field is focused. Suggestions filter as you type and use Sonetro’s existing appearance.
- Selecting a server suggestion fills its address and account details. Connection history retains up to 10 successful connections without storing passwords in the history; enter your password or sign in again to connect.
- History removal now removes only the history entry. Playing the song again can add it back.
- New removal now hides the song from recent additions across restarts while keeping it in the library.
- Playlist removal targets playlist membership, and Offline uses the dedicated remove-download action. Favorites and Queue retain their own removal behavior; library removal remains separate from file deletion.
- Improved Back navigation and duplicate-destination handling. Returning to Live no longer scrolls through the panorama; leaving the app keeps background playback available.
- Updated Add to to use the shared source-filter dialog layout and transitions.
- Simplified lyrics footers to source attribution without timestamp-availability notices.

## Validation

Source compilation and targeted regression checks passed for navigation, removal scope, offline removal, search-result publication, and server-history ordering. The supplied APK’s package version and signature were verified. On-device keyboard and transition verification remains outstanding.
