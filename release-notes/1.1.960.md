# Sonetro 1.1.960

This release adds internet radio to the shared music experience and improves navigation, artist backgrounds, and transition efficiency.

## Radio+

- Browse **Genre, Recents, Local Radio, Location, Most Popular, and Saved** through the shared panorama. Saved replaces Trending; separate favorites-screen shortcuts have been removed.
- Search the global Radio Browser catalogue with partial matching across station names, countries, regions, genres/tags, and languages. Optional country, genre, language, location, and popularity filters refine the same search.
- Search uses a short debounce, cancels superseded requests, ranks exact station-name matches first, removes duplicate station IDs, supports incremental loading, and provides loading, empty, retry, and network-error states.
- Save stations with a star from station rows or the Live drawer, or use the minimal favorite/remove-favorite contextual action. Favorite state is shared throughout Radio and persists across restarts.
- Recents keeps the most recently played station first, moves replayed stations to the top, and avoids duplicate station IDs.
- Local Radio uses approximate location to identify the user's country. Location browsing independently offers countries and available regions/cities, skipping unsupported levels.
- Most Popular is global and uses the provider’s cumulative community-vote ranking. It is not a live listener count.
- Expanded UK station coverage with the ordered registry and bundled station covers, including additional requested stations where available.

## Playback and navigation

- Radio uses the main Live player, station cover artwork, available broadcast title/artist information, and a scan action for moving to another station.
- “Add to…” remains visible but is greyed out and inactive while the current playback source is radio. It becomes available again for music.
- Back from Live preserves the originating music or radio list/menu. Radio searches keep their query and results when returning from playback.
- Collection now lists **music, artists, albums, playlists, downloads, and radio+**. Radio+ is opened from Collection rather than included in the music library’s horizontal pages.
- Radio supporting text uses the same spacing as the music library filter row.

## Artwork, widgets, and motion

- A custom artist background applies to all songs by that artist. The menu opens the device image picker directly, or shows remove background when an override is set.
- Refined compact widget previews and preview-label spacing.
- Reused page-turn animation definitions and frame resources, reduced repeated queue preparation on navigation into Live, and improved shuffle-all queue reuse.
- Reused Live next/previous cover-slide definitions and removed unnecessary fixed-tile size animation while preserving the existing motion style and timing.

## Availability and validation

Android 7.0 (API 24) or newer is required. Station availability, broadcast metadata, and city/network coverage depend on the directory and broadcaster. Fine-grained location levels are shown only when supported by station metadata.

Source compilation and 38 targeted Radio/navigation unit tests passed during development; device-test sources also compiled. Read-only provider checks covered BBC, Bangladesh, Tokyo, jazz, French-language queries, and ranking endpoints. These checks do not establish universal station coverage or guarantee frame performance on every device. The supplied signed APK’s version, signature, and checksum were verified.
