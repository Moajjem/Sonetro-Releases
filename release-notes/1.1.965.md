# Sonetro 1.1.965

This release focuses on browsing music by genre and refining the shared library selection experience.

## Genre browsing

- Replaced Radio+ in Collection with **Genres**, using genre metadata from the existing music library. Tracks without genre information are grouped under “unknown genre”.
- Integrated Genres into the shared library panorama, between Albums and Playlists.
- Selecting a genre opens a dedicated detail page with the **GENRES** heading, genre name, and one source-filter row. Songs no longer open inline beneath duplicate “showing” labels.
- Reused the existing page-turn transition, song list, long-press actions, and selection system.
- Preserved the genre detail page when opening Live playback so Back returns to the browsing context.
- Simplified genre details by removing Search, Refresh, and the play button beside the heading.

## Selection controls

- Replaced Settings with **select all** in the shared song-selection menu, alongside **add to…**.
- Select all selects the current selection scope. It remains visible, greyed out, and inactive once all songs are selected, and becomes available again when a song is deselected.
- The removal button remains visible but disabled when no songs are selected. Existing context-specific removal behavior is preserved.
- Add to… is disabled while the selection is empty.

## Radio availability

Internet radio is unavailable in this version. Collection now focuses on music, artists, albums, playlists, downloads, and genres.

## Installation

Download **Sonetro-1.1.965-release.apk** from this release. Android **7.0 or newer** is required. Install over an existing compatible Sonetro installation to retain app data; Android requires matching signing certificates for an in-place update.
