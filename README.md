# Sonetro-Releases

Added native Plex and Jellyfin support for easier server discovery, setup, and playback.
Added Remove from Library, allowing songs to be hidden from your library without deleting the original files.
Improved library management with clearer confirmation when removing individual songs or multiple selections, while keeping playlist removal separate.
Improved permanent song deletion with safer system handling and clearer confirmation.
Added a new heart shower animation and refined favorite icon transitions.
Added support for custom song and artist background images.
Improved large headings so they automatically resize to stay on one line across different screen sizes and accessibility font settings.
Improved playback reliability, including better resume behavior and more reliable reconnection after interruptions.
Improved the Up Next ticker so predictions update more naturally based on the current song.
Added new accent colors: Black, White, Coral, and Indigo, with improved contrast throughout the interface.
Renamed the Look settings section to Appearance and refined library selection screens.
Improved compatibility with Plex, Jellyfin, Subsonic, and local network music servers.
Completely redesigned home screen widgets with 19 adaptive layouts that respond to different widget sizes.
Added a circular Vinyl widget style with refined visuals and a new progress ring.
Widget playback progress now updates much more smoothly and frequently.
Improved widget performance, memory usage, artwork loading, and recovery from failed cover requests.
Improved remote artwork detection, including better support for Subsonic cover art.
Added a new Windows Phone 7-inspired dialog animation, with menus unfolding from a horizontal line into the full panel.
Improved dialog background dimming for more consistent visuals across different screen sizes and system bars.
Improved widget text sizing, progress indicators, responsive layouts, dynamic theming, and artwork persistence.
Improved widget reconnection and playback state recovery after service restarts.
Various stability, performance, playback, widget, library, animation, and visual improvements throughout the app.
